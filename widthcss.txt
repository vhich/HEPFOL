| Tailwind       | Meaning                         |
| -------------- | ------------------------------- |
| `w-*`          | Width                           |
| `min-w-*`      | Minimum width                   |
| `max-w-*`      | Maximum width                   |
| `h-*`          | Height                          |
| `min-h-*`      | Minimum height                  |
| `max-h-*`      | Maximum height                  |
| `w-full`       | 100% width                      |
| `w-screen`     | 100vw                           |
| `h-full`       | 100% height                     |
| `h-screen`     | 100vh                           |
| `min-h-screen` | At least viewport height        |
| `max-w-full`   | Maximum width = 100%            |
| `max-w-none`   | No maximum width                |
| `mx-auto`      | Center horizontally             |
| `w-1/2`        | 50% width                       |
| `w-1/3`        | 33.33% width                    |
| `w-2/3`        | 66.67% width                    |
| `md:w-*`       | Change width at `md` breakpoint |
| `lg:w-*`       | Change width at `lg` breakpoint |
